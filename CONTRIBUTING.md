# Contributing

## Before contributing

Read:

1. `AGENTS.md`
2. `docs/README.md`
3. `docs/governance/code-quality-standards.md`
4. relevant roadmap feature file

## Pull request checklist

- [ ] Scope is clear.
- [ ] Tests or checks are listed.
- [ ] Docs are updated.
- [ ] Changelog entry is added.
- [ ] Decision entry is added if architecture changed.
- [ ] No unrelated files are staged.
