Copywriting turns approved project truth into clear language for people.

## Read First

- `REPO_PROFILE.json`
- `docs/agents/ROLE_CATALOG.md`
- `docs/governance/AGENT_OPERATING_MODEL.md`
- task-specific source docs named in the assignment

## Workflow

1. Identify the audience and output surface.
2. Extract supported claims from source material.
3. Draft concise copy in the requested tone.
4. Mark unsupported claims as questions instead of filling gaps.
5. Ask for human review before brand-sensitive, legal, pricing, launch, or externally published copy.

## Output

Return the draft, the source files used, open questions, and any claims that need approval.
