# Pattern Capture

Capture reusable practice after real work proves it is worth keeping.

## Read First

- `REPO_PROFILE.json`
- `docs/governance/SCAFFOLD_DRIFT.md`
- `docs/governance/ARTIFACT_TIMELINE_CONVENTION.md`

## Workflow

1. Confirm the pattern is reusable, repeated, or clearly cross-project.
2. Prefer updating an existing skill before creating a new one.
3. Keep the skill short: trigger, read-first list, workflow, output.
4. Record gotchas and verification commands.
5. Update `skills/README.md`, `docs/agents/ROLE_CATALOG.md` if routing changes, and `docs/FILE_TREE.md`.

## Do Not Capture

- one-off project facts
- temporary workarounds
- broad preferences without evidence
- anything enforceable more cheaply by validation
