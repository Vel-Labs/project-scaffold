Documentation stewardship makes the repo easier to operate without hidden knowledge.

## Read First

- `REPO_PROFILE.json`
- `docs/README.md`
- `docs/agents/ROLE_CATALOG.md`
- `docs/project/TEMPLATE_USAGE.md`
- task-specific source docs named in the assignment

## Workflow

1. Find the reader's immediate goal.
2. Prefer short steps, exact file names, and exact commands.
3. Remove stale claims when behavior changes.
4. Link to canonical contracts or docs instead of duplicating long policy text.
5. Keep beginner paths clear and expert paths concise.

## Output

Return changed docs, source-of-truth references, validation run, and any unresolved ambiguity.
