# Human Copy Review

Use this skill to make text sound natural while preserving truth.

## Read First

- `REPO_PROFILE.json`
- `docs/agents/ROLE_CATALOG.md`
- source material named in the assignment

## Review Lens

- Replace generic claims with specific, supported language.
- Prefer plain verbs and concrete nouns.
- Cut filler, hype, and corporate rhythm.
- Keep the user's intended voice and audience.
- Do not add claims not supported by source material.

## Output

Return revised copy, what changed, unsupported claims removed or flagged, and any approval questions.
