# Work Log

Append one short entry when a meaningful bulk of work ships. Newest entries go at the bottom.

Use this for fast human or agent catch-up. Detail belongs in commits, decisions, receipts, audits, or changed files.

## Entry Grammar

```md
## YYYY-MM-DD - Short title - #tag
What: Outcome first, in one or two lines.
Refs: commit `abc123`, doc `docs/path.md`
```

## Tags

Reuse before inventing: `#governance`, `#runtime`, `#skill`, `#docs`, `#quality`, `#research`, `#release`.
