# Governance

This folder defines how `<PROJECT_NAME>` stays orderly while moving quickly.

Governance files are operating law for the scaffold. Do not change them without explicit human authorization unless the task is specifically governance maintenance.

## Files

```text
AUDIT_PHILOSOPHY.md          audit doctrine
multi-agent-workflow.md      how multiple humans/agents coordinate
worktree-governance.md       branch and worktree rules
code-quality-standards.md    readability, line count, comment, and module rules
phase-cadence.md             .1-.9 phase execution pattern
open-source-governance.md    public repo posture
AI_USAGE.md                  AI/tool usage disclosure and review trail
```

`REPO_PROFILE.json` lists governance-locked and architecture-locked paths for agents that need a compact machine-readable boundary.
