# Governance Learnings

This file records durable patterns learned from repeated receipts, audits, reviews, and scaffold adoption work.

Learnings are advisory. They may refine prompts, checklists, examples, and future proposals, but they do not override contracts, schemas, policies, source-authority records, or human approvals.

## Distillation Rules

- Keep each learning tied to visible evidence: receipt ids, audit files, review notes, or source paths.
- Prefer Do/Don't guidance with enough context to apply it in another project.
- Mark uncertainty when the evidence is weak, partial, or project-specific.
- Promote repeated audit findings through `contracts/agent-governance/workflows/learning-distillation.json`.
- Update contracts separately when a learning proves a durable rule that should become enforcement.
