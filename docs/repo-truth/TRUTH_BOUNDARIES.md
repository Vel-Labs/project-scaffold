# Truth Boundaries

## Durable truth

- contracts
- schemas
- configuration
- deployed addresses
- logs
- receipts
- tests
- audits
- decision records

## Not enough by itself

- screenshots
- chat transcripts
- frontend labels
- unverified claims
- generated text
- hard-coded demo data

## Claim levels

| Level | Meaning |
| --- | --- |
| Planned | not implemented |
| Scaffolded | structure exists |
| Fixture-proven | deterministic local proof exists |
| Testnet-proven | deployed or integration proof exists |
| Demo-proven | shown in demo |
| Submission-proven | included in final submission |
