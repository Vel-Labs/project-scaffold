# Decisions

Detailed durable architectural and governance decisions live here.

Root `DECISIONS.md` is the curated index and summary. Dated files in this folder hold detailed entries.

## Structure

```text
DECISIONS.md                  root summary and index
docs/decisions/2026-04-26.md  detailed daily log
```

## Rules

- Root `DECISIONS.md` summarizes and links.
- Dated files hold detailed entries.
- Do not duplicate full decision entries between root and dated files.
- Routine implementation notes belong in `CHANGELOG.md`, audits, or handoffs.
